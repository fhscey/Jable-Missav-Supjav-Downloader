> AVDL 是一款专为影音爱好者打造的高性能现代化桌面客户端。打破传统网页繁琐的翻页与等待，将多个主流站点的内容汇聚于一张流畅顺滑的无界画布之中，带来前所未有的浏览、预览、在线播放与一键下载体验。客户端便携版仅约 **10 MB**，毫秒级快速启动，资源占用极低。**推荐全屏使用。**

## ✨ 核心产品亮点

### 🌌 无界探索画布 (Infinite Canvas)

- **打破传统翻页束缚**：摒弃传统网站死板的九宫格与翻页按键，所有影片以平铺交互形式呈现于无限画布中。
- **自由缩放与平移**：支持鼠标滚轮无级缩放视口、自由拖拽平移，如浏览全景地图般自由畅快，海量内容尽在掌握。
- **动态视野渲染**：超高帧率平滑过渡，无论画布容纳多少内容均能保持如丝般顺滑的操作响应。

![预览图](./docs/img/preview.webp)

### 🎬 在线即点即看 (内置极速播放器)

- **无需漫长等待**：告别“必须全部下载完才能看”的繁琐流程，鼠标左键轻点任意卡片，即刻开启在线沉浸式播放。
- **完整播放控制**：内置全功能播放器，支持画质自适应、秒速进度拖拽、全屏观看及沉浸式全黑影院模式。

### 🔍 深度元数据与右键详情

- **右键快速透视**：右键点击任意影片卡片，即时呼出详情弹窗。
- **丰富关联信息**：番号、女优、分类标签、类别一览无余。

### 📥 极速离线下载引擎

- **一键极速加入**：悬停卡片点击左上角图标，即可瞬时加入下载队列。
- **稳定断点续传**：支持多任务并发高速下载，遇到网络波动或意外中断自动保留进度，后续随时继续，绝不重复下载。

### 🌐 多站点聚合与智能网络感知

- **多平台无缝切换**：一键在 JableTV、MissAV、SupJav 等多个主流内容源之间平滑切换。
- **强大的筛选导航**：支持分类标签抽屉、排行榜、最新发布、最高热度等多种排序模式，配合即时搜索框快速锁定心仪作品。
- **智能代理自适应**：自动侦测并对接系统代理工具（如 Clash Verge 等），亦支持手动配置专用网络节点，跨区浏览稳定无忧。

## 📦 我该下载哪个版本

AVDL 为每个主流平台均提供了 **标准安装版** 与 **便携免安装版**（共 6 款专属发布文件），请根据您的操作系统与使用习惯自由选择：

> 重要：必须确保已安装 `ffmpeg`，请自行从 ffmpeg官网/github 下载，并加入环境变量 PATH. 详情咨询任意 AI。

| 操作系统    | 架构                             | 文件格式 / 产物名         | 说明与使用建议                                                                        |
| :---------- | :------------------------------- | :------------------------ | :------------------------------------------------------------------------------------ |
| **Windows** | x64 (64位)                       | `avdl_*_x64-setup.exe`    | **安装版**：标准安装向导，自动创建桌面快捷方式，推荐大多数 Windows 用户               |
|             |                                  | `AVDL_*_windows_x64.exe`  | **便携版（免安装）**：单文件绿色版，双击直接运行，可随意放在 U 盘或移动硬盘           |
| **macOS**   | Apple Silicon (arm64, M系列芯片) | `avdl_*_aarch64.dmg`      | **镜像安装包**：双击挂载 DMG 镜像，将图标拖入 Applications 文件夹即可                 |
|             |                                  | `AVDL_*_mac_arm64.zip`    | **便携压缩包**：解压即可直接提取独立可执行文件使用                                    |
| **Linux**   | x64 (64位)                       | `avdl_*_amd64.AppImage`   | **标准安装包**：跨发行版通用，添加执行权限后双击即可运行（Ubuntu / Fedora / Arch 等） |
|             |                                  | `AVDL_*_linux_x64.tar.gz` | **便携压缩包**：解包即得 `avdl` 独立二进制程序，适合高级用户与脚本调用                |

> 提示：文件名小写前缀（如 `avdl_...`）为平台标准安装包，大写前缀（如 `AVDL_...`）为免安装便携版。

## 🍎 macOS 首次运行说明

由于本软件为开源未签名应用，首次在 macOS 上运行时若提示“无法打开”或“已损坏”，可在系统**终端 (Terminal)** 中执行以下命令解除 Gatekeeper 隔离：

```bash
# 若使用的是安装到应用程序目录的 .app 应用：
xattr -cr /Applications/avdl.app

# 若使用的是便携版单个可执行文件：
xattr -cr ./avdl
```

执行后即可正常双击启动。

## 🛠️ 本地开发与构建

如需基于源码自行构建：

1. **环境准备**：
   - 安装 [Bun](https://bun.sh/)（推荐）或 Node.js (v18+)
   - 安装 [Rust](https://rustup.rs/) (1.75+)
   - 确保系统已安装 `ffmpeg` 并加入环境变量 PATH

2. **安装依赖**：

   ```bash
   bun install
   ```

3. **启动调试**：

   ```bash
   bun run tauri dev
   ```

4. **构建打包**：
   ```bash
   bun run tauri build
   ```
