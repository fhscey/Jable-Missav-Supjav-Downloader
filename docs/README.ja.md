# AVDL - AVブラウジング＆ダウンローダー

Language: [简体中文](../README.md) | [繁體中文](README.zh-TW.md) | [English](README.en.md) | **日本語**

Discord: [Discord コミュニティに参加](https://discord.gg/GACc7HhHY)

> **超軽量 · 即時ストリーミング再生**  
> AVDL は、映像ファンのために開発された高性能でモダンなデスクトップクライアントです。従来のウェブサイトにおける煩わしいページネーションや待機時間を排除し、複数の主要サイトのコンテンツをシームレスな無限キャンバスに集約。これまでにない自由な探索、プレビュー、インライン再生、ワンクリック高速ダウンロード体験を提供します。ポータブル版のファイルサイズはわずか **約 10 MB**、ミリ秒単位で高速起動し、リソース消費も極めて低く抑えられています。**全画面表示でのご利用を推奨します。**

---

## ✨ 主な機能と特徴

### 🌌 無限探索キャンバス (Infinite Canvas)

- **ページ送りの束縛から解放**：従来の固定グリッドやページ送りボタンを廃止し、すべての動画カードを広大な無限キャンバス上にインタラクティブに配置。
- **自由なズーム＆パン**：マウスホイールによる無段階ズーム、ドラッグによる直感的な視点移動に対応。全体マップを俯瞰するかのように、膨大なコンテンツを自由自在に探索できます。
- **動的ビューポート最適化**：高フレームレートでのスムーズな描画遷移を実現し、キャンバス上にどれほどコンテンツがあっても快適な操作レスポンスを維持します。

![プレビュー](./img/preview.webp)

### 🎬 ワンクリック即時再生 (内蔵高速プレイヤー)

- **ダウンロード完了を待つ必要なし**：動画カードを左クリックするだけで、ストリーミング再生が即座にスタート。
- **充実のプレイヤー機能**：自動画質選択、ミリ秒単位のシークバー移動、全画面表示、没入感の高いシネマダークモードを標準搭載。

### 🔍 右クリック詳細ポップオーバー

- **右クリックで即座に確認**：動画カードを右クリックすると、瞬時に詳細ポップオーバーを展開。
- **豊富なメタデータ表示**：品番（コード）、出演女優、カテゴリタグ、高解像度カバー画像をその場で一目で確認できます。

### 📥 高速レジューム対応ダウンロードエンジン

- **ワンクリックで即キュー登録**：カード左上のアイコンをクリックするだけで、ダウンロードキューへ瞬時に追加。
- **安定したレジューム（中断再開）**：複数タスクの並行高速ダウンロードに対応。通信切断やアプリ終了時もダウンロード済みセグメントを確実に保存し、重複ダウンロードを防ぎます。

### 🌐 複数サイト統合＆スマートネットワーク検知

- **複数プロバイダーのシームレス切替**：JableTV、MissAV、SupJav などの主要サイト間をワンクリックでスムーズに切り替え。
- **強力なフィルター＆ソート**：カテゴリタグドロワー、人気ランキング、最新順、再生数順など多彩な並び替えと即時キーワード検索に対応。
- **システムプロキシ自動連携**：システムプロキシ（Clash Verge など）を自動検知して連携。カスタムプロキシの設定にも対応し、地域制限を回避した安定ブラウジングを実現します。

## 🖱️ 操作・ショートカットガイド

マウスおよびトラックパッドのみで直感的に全操作が可能です（中ボタンドラッグで移動、右クリックで詳細、左クリックで再生）。

| 操作 | 入力方法 | 説明 |
| :--- | :--- | :--- |
| **キャンバス移動** | マウス中ボタンドラッグ / トラックパッドの2本指スワイプ | キャンバス全体を自由に移動 |
| **ズームイン/アウト** | (`Cmd`+ホイール, `Ctrl`+ホイール) / 上部ズームバー / `+` `-` キー / ピンチイン・アウト | 表紙詳細の拡大や全体の俯瞰 |
| **視点リセット** | 上部ズームバーの中央ボタン / `0` キー | 視点をすばやく中央原点にリセット |
| **オンライン再生** | 動画カードを左クリック | 内蔵プレイヤーで即座に再生を開始 |
| **詳細確認** | 動画カードを右クリック | 詳細ポップオーバーを表示（品番・女優・タグ・高画質画像） |
| **動的プレビュー** | 動画カードにマウスホバー | 音声なしのミニプレビュー動画を自動ロード |
| **動画検索** | スラッシュ `/` キーで動画を検索、`Esc` で終了 | 現在閲覧中のサイト内を検索 |
| **タグ検索** | 左側ナビゲーション内で `Cmd + k` または `Ctrl + k`、`Esc` で終了 | カテゴリやタグをすばやく絞り込み・検索 |
| **高速ダウンロード** | カード左上アイコンまたは詳細画面から追加 | 追加時は一時停止状態でキューに入ります。下部ダウンロード管理から開始 |
| **接続を切断** | `Option+z` または `Alt+z` / 左下の切断ボタン | サイトとの接続を即座に切断して初期画像を表示、忙しい右手を解放します |

## 📦 ダウンロードするパッケージの選び方

AVDL は各主要プラットフォーム向けに **標準インストーラー版** と **ポータブル（インストール不要）版** の計 6 種類のリリースファイルを提供しています：

> **重要**：システムに `ffmpeg` がインストールされ、環境変数 `PATH` に通っている必要があります。公式サイトまたは GitHub から入手してください。

| OS | アーキテクチャ | 形式 / ファイル名 | 説明と推奨用途 |
| :--- | :--- | :--- | :--- |
| **Windows** | x64 (64-bit) | `avdl_*_x64-setup.exe` | **インストーラー版**：標準セットアップウィザード、デスクトップショートカット作成（一般ユーザー向け） |
| | | `AVDL_*_windows_x64.exe` | **ポータブル版**：単一実行ファイル、USBメモリ等に入れてそのまま利用可能 |
| **macOS** | Apple Silicon (arm64, Mシリーズ) | `avdl_*_aarch64.dmg` | **DMGイメージ**：ダブルクリックでマウントし、Applications フォルダにドラッグ＆ドロップ |
| | | `AVDL_*_mac_arm64.zip` | **ポータブル圧縮版**：解凍して独立した実行ファイルをそのまま利用 |
| **Linux** | x64 (64-bit) | `avdl_*_amd64.AppImage` | **AppImage版**：主要ディストリビューション共通、実行権限付与でそのまま起動可能 |
| | | `AVDL_*_linux_x64.tar.gz` | **ポータブル圧縮版**：`avdl` バイナリを直接抽出（上級者・スクリプト連携向け） |

> 注：小文字プレフィックス（`avdl_...`）は標準インストーラー、大文字プレフィックス（`AVDL_...`）はインストール不要のポータブル版です。

## 🍎 macOS 初回起動時のご注意

本アプリはオープンソースの未署名バイナリとして配布されているため、macOS の Gatekeeper により「開発元が未確認のため開けません」または「壊れているため開けません」と表示される場合があります。その際は**ターミナル (Terminal)** で以下のコマンドを実行してください：

```bash
# Applications フォルダに配置した .app の場合：
xattr -cr /Applications/avdl.app

# ポータブル版の単一実行ファイルの場合：
xattr -cr ./avdl
```

実行後、通常どおりダブルクリックで起動できるようになります。

## 🛠️ ローカル開発・ビルド方法

ソースコードから自身でビルドする場合：

1. **環境要件**：
   - [Bun](https://bun.sh/)（推奨）または Node.js (v18+)
   - [Rust](https://rustup.rs/) (1.75+)
   - システムに `ffmpeg` がインストールされ、`PATH` に登録されていること

2. **依存関係のインストール**：

   ```bash
   bun install
   ```

3. **開発サーバー起動**：

   ```bash
   bun run tauri dev
   ```

4. **本番ビルド**：
   ```bash
   bun run tauri build
   ```
