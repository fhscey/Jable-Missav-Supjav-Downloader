# AVDL - AV瀏覽與下載神器

Language: [简体中文](../README.md) | **繁體中文** | [English](README.en.md) | [日本語](README.ja.md)

> **極致輕量 · 線上暢看**  
> AVDL 是一款專為影音愛好者打造的高性能現代化桌面客戶端。打破傳統網頁繁瑣的翻頁與等待，將多個主流站點的內容匯聚於一張流暢順滑的無界畫布之中，帶來前所未有的瀏覽、預覽、線上播放與一鍵下載體驗。客戶端便攜版僅約 **10 MB**，毫秒級快速啟動，資源佔用極低。**推薦全螢幕使用。**

## ✨ 核心產品亮點

### 🌌 無界探索畫布 (Infinite Canvas)

- **打破傳統翻頁束縛**：摒棄傳統網站死板的九宮格與翻頁按鍵，所有影片以平鋪互動形式呈現於無限畫布中。
- **自由縮放與平移**：支援滑鼠滾輪無級縮放視口、自由拖曳平移，如瀏覽全景地圖般自由暢快，海量內容盡在掌握。
- **動態視野渲染**：超高幀率平滑過渡，無論畫布容納多少內容均能保持如絲般順滑的操作響應。

![預覽圖](./img/preview.webp)

### 🎬 線上即點即看 (內建極速播放器)

- **無需漫長等待**：告別「必須全部下載完才能看」的繁瑣流程，滑鼠左鍵輕點任意卡片，即刻開啟線上沉浸式播放。
- **完整播放控制**：內建全功能播放器，支援畫質自適應、秒速進度拖曳、全螢幕觀看及沉浸式全黑劇院模式。

### 🔍 深度元數據與右鍵詳情

- **右鍵快速透視**：右鍵點擊任意影片卡片，即時呼出詳情彈窗。
- **豐富關聯資訊**：番號、女優、分類標籤、類別一覽無餘。

### 📥 極速離線下載引擎

- **一鍵極速加入**：懸停卡片點擊左上角圖示，即可瞬時加入下載佇列。
- **穩定斷點續傳**：支援多任務並發高速下載，遇到網路波動或意外中斷自動保留進度，後續隨時繼續，絕不重複下載。

### 🌐 多站點聚合與智慧網路感知

- **多平台無縫切換**：一鍵在 JableTV、MissAV、SupJav 等多個主流內容源之間平滑切換。
- **強大的篩選導航**：支援分類標籤抽屜、排行榜、最新發布、最高熱度等多種排序模式，配合即時搜尋框快速鎖定心儀作品。
- **智慧代理自適應**：自動偵測並對接系統代理工具（如 Clash Verge 等），亦支援手動配置專用網路節點，跨區瀏覽穩定無憂。

## 🖱️ 操作與快捷指南

可完全滑鼠控制，中鍵拖曳，右鍵詳情，左鍵播放。

| 操作         | 互動方式                                                                         | 功能說明                                       |
| :----------- | :------------------------------------------------------------------------------- | :--------------------------------------------- |
| **畫布平移** | 滑鼠中鍵(按壓)拖曳 / 觸控板雙指滑動                                              | 自由移動視角探索整張畫布                       |
| **畫布縮放** | (`Command`+滾輪, `Ctrl` + 滾輪) / 頂部控制條縮放 / `+` `-` 鍵 / 觸控板雙指放大縮小 | 放大查看封面細節，縮小鳥瞰全域分佈             |
| **重置視角** | 頂部控制條回中 / 按 `0` 鍵                                                       | 視口迅速回中                                   |
| **線上播放** | 滑鼠左鍵點擊影片卡片                                                             | 調出內建播放器直接線上流暢觀看                 |
| **查看詳情** | 滑鼠右鍵點擊影片卡片                                                             | 彈出詳情卡片（番號、演員、標籤及高畫質大圖）   |
| **動態預覽** | 滑鼠懸停在影片卡片上                                                             | 自動載入靜音短影片動態預覽                     |
| **搜尋影片** | 按斜線 `/` 搜尋影片，按 `Esc` 退出搜尋                                           | 搜尋目標網站為目前正在瀏覽的網站               |
| **搜尋標籤** | 在左側導覽列按 `Command + k` 或 `Ctrl + k` 搜尋標籤，按 `Esc` 退出搜尋           | 快速過濾與定位分類標籤                         |
| **快速下載** | 點擊卡片左上角下載按鈕，或從詳情頁加入下載佇列，在底部下載管理中啟動下載         | 點擊下載僅加入佇列，預設暫停狀態，需要手動啟動 |
| **中斷連線** | `Option+z` 或 `Alt+z` / 左下角中斷連線按鈕                                       | 立刻中斷與站點的連線，顯示初始圖片，解放你繁忙的右手 |

## 📦 我該下載哪個版本

AVDL 為每個主流平台均提供了 **標準安裝版** 與 **便攜免安裝版**（共 6 款專屬發布檔案），請根據您的作業系統與使用習慣自由選擇：

> 重要：必須確保已安裝 `ffmpeg`，請自行從 ffmpeg 官網/github 下載，並加入環境變數 PATH。詳情可諮詢任意 AI。

| 作業系統    | 架構                             | 檔案格式 / 產物名         | 說明與使用建議                                                                        |
| :---------- | :------------------------------- | :------------------------ | :------------------------------------------------------------------------------------ |
| **Windows** | x64 (64位元)                     | `avdl_*_x64-setup.exe`    | **安裝版**：標準安裝精靈，自動建立桌面捷徑，推薦大多數 Windows 使用者                |
|             |                                  | `AVDL_*_windows_x64.exe`  | **便攜版（免安裝）**：單檔案綠色版，按兩下直接執行，可隨意放在隨身碟或行動硬碟        |
| **macOS**   | Apple Silicon (arm64, M系列晶片) | `avdl_*_aarch64.dmg`      | **映像檔安裝包**：按兩下掛載 DMG 映像檔，將圖示拖入 Applications 資料夾即可           |
|             |                                  | `AVDL_*_mac_arm64.zip`    | **便攜壓縮包**：解壓縮即可直接提取獨立可執行檔案使用                                  |
| **Linux**   | x64 (64位元)                     | `avdl_*_amd64.AppImage`   | **標準安裝包**：跨發行版通用，新增執行權限後按兩下即可執行（Ubuntu / Fedora / Arch 等） |
|             |                                  | `AVDL_*_linux_x64.tar.gz` | **便攜壓縮包**：解壓縮即得 `avdl` 獨立二進位程式，適合進階使用者與腳本呼叫            |

> 提示：檔案名稱小寫前綴（如 `avdl_...`）為平台標準安裝包，大寫前綴（如 `AVDL_...`）為免安裝便攜版。

## 🍎 macOS 首次執行說明

由於本軟體為開源未簽章應用程式，首次在 macOS 上執行時若提示「無法打開」或「已損毀」，可在系統**終端機 (Terminal)** 中執行以下指令解除 Gatekeeper 隔離：

```bash
# 若使用的是安裝到應用程式目錄的 .app 應用：
xattr -cr /Applications/avdl.app

# 若使用的是便攜版單個可執行檔案：
xattr -cr ./avdl
```

執行後即可正常按兩下啟動。

## 🛠️ 本地開發與建置

如需基於原始碼自行建置：

1. **環境準備**：
   - 安裝 [Bun](https://bun.sh/)（推薦）或 Node.js (v18+)
   - 安裝 [Rust](https://rustup.rs/) (1.75+)
   - 確保系統已安裝 `ffmpeg` 並加入環境變數 PATH

2. **安裝依賴**：

   ```bash
   bun install
   ```

3. **啟動除錯**：

   ```bash
   bun run tauri dev
   ```

4. **打包建置**：
   ```bash
   bun run tauri build
   ```
